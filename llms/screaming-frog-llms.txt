# Screaming Frog

> Screaming Frog Ltd is a UK-based SEO software company and search marketing agency in
> Henley-on-Thames, Oxfordshire. It publishes two desktop applications — the SEO Spider
> website crawler and the Log File Analyser — sold as annual per-user licences with
> functional free tiers. Screaming Frog does not operate a public web API. Its
> machine-callable surfaces are the SEO Spider command line interface and, since version
> 24.0 (19 May 2026), a first-party Model Context Protocol server built into the desktop
> application.

## What an agent can actually call

- No REST API, no GraphQL endpoint, no AsyncAPI, no webhooks, no A2A agent card. All
  probed on 2026-08-13; all 404.
- **MCP server** — 29 tools, prefixed `sf_`, exposing crawl control, reports, bulk
  exports, SEO element datasets, URL inspection, screenshots, embeddings, a Node.js script
  runner and sandboxed filesystem access. It runs *inside the user's licensed desktop
  install*: STDIO transport via a Claude Desktop extension, or a Streamable HTTP transport
  on `http://localhost:11435/mcp`. There is no internet-reachable endpoint. Paid licence
  only.
- **CLI** — the SEO Spider runs fully headless from the command line: crawl, configure,
  compare, export, report, schedule.

## Products

- [SEO Spider](https://www.screamingfrog.co.uk/seo-spider/): Desktop website crawler for
  Windows, macOS, Ubuntu and Fedora that performs technical SEO audits — broken links,
  titles and metadata, duplicate content, redirects, hreflang, AMP, structured data,
  accessibility, Core Web Vitals, XML sitemap generation and crawl comparison. Current
  version 24.3 (29 June 2026). Free to 500 URLs per crawl; £199/user/year unlimited.
- [Log File Analyser](https://www.screamingfrog.co.uk/log-file-analyser/): Desktop tool for
  uploading and analysing server log files to see how search bots crawl a site. Current
  version 7.1. Free to 1,000 log lines and one project; £99/user/year unlimited.

## APIs Screaming Frog consumes

The SEO Spider is primarily an API *consumer*. During a crawl it can pull data from
Google Analytics (Universal and GA4), Google Search Console including the URL Inspection
API, PageSpeed Insights / Lighthouse, Ahrefs, Majestic, Moz, OpenAI, Gemini and Ollama.
Credentials for these are the customer's own and are stored locally; the quotas, costs and
rate limits belong to those providers, not to Screaming Frog.
